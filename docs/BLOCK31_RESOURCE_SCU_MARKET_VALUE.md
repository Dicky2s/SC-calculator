# Block 31 — Resource SCU + processed market value preview

Adds a visible preview table in the resource capture block:

- scan percent -> estimated SCU;
- resource -> configured refined market price per SCU;
- estimated processed value in aUEC;
- total percent / total estimated SCU / total estimated value.

Prices live in `configs/resource_prices.yaml` and are editable local seed values.
They are meant for planning and analytics, not as authoritative live economy data.
